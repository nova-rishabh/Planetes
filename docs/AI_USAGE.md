# AI usage disclosure

Team Planetes used AI assistants as coding and writing tools. The science, data choices and final decisions are the team's own.

## Tools

| Tool | Used by | What it helped with |
|---|---|---|
| Claude Code (Anthropic) | Rishabh | Much of the web app, API and pipeline code, the documentation, and the code that renders the launch film |
| ChatGPT (OpenAI) | Shivaansh | First draft of the target resolver and its tests |
| Antigravity (Google Gemini) | Shivaansh | First draft of the Gaia and AllWISE overlay code |

## How we kept it honest

- Every piece of AI-assisted code was reviewed and tested by the team before it went in: unit tests, contract validation against the JSON Schemas, and checks against real SPHEREx data.
- Every scientific number on the site comes from real archive data and is checked against a known answer on the Validation page ([VALIDATION.md](VALIDATION.md)).
- No image, spectrum or number on the site or in the launch film is AI-generated. All imagery is real SPHEREx data from NASA/IPAC IRSA; the film's music and sound effects are CC0 recordings from Openverse.
- Results are worded "consistent with", never "discovered".
